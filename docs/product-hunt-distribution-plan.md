## Community Plan

### Priority 1 - X / Nullhype

Post from `@nullhypeai` first once the Product Hunt page is live.

Use the primary Nullhype post. Pin it for launch day. Add the self-reply within 5 minutes, then reply to every serious comment with product-specific context.

Before posting, leave 3-5 high-signal replies under relevant builder / indie hacker / Product Hunt launch posts. Do not ask for upvotes. Ask for honest feedback.

### Priority 2 - Existing Build-In-Public Thread

Reply to the strongest prior HypeCheck / Nullhype build-in-public thread with the short X version.

Frame it as a continuation of the build, not a generic launch announcement.

### Priority 3 - r/SideProject

Skip for this launch unless the Reddit account has enough karma and posting history.

Post only if the account has enough Reddit history to avoid looking like a drive-by promo.

Recommended angle: feedback request with screenshots.

Title:

`I built an AI reality check for startup ideas. Looking for brutal feedback.`

Body:

`I built HypeCheck to stress-test startup ideas before spending weeks building them. You enter a rough idea and get a report with a Hype Score, competitors, market sizing, execution risks, monetization viability, demand signals, and a build / don't build verdict.`

`I am especially looking for feedback on whether the report is useful enough to change what you build next, and which section you would trust least.`

`Product Hunt: https://www.producthunt.com/posts/hypecheck`

### Priority 4 - r/IndieHackers

Skip for this launch unless the account has enough posting history.

Use a story-first post, not a launch pitch.

Title:

`I launched my first end-to-end indie product. The goal is one paying stranger.`

Body angle:

- Built HypeCheck as a practical full-stack learning and monetization project.
- Stack: Next.js, Supabase, Claude, Dodo Payments, Vercel.
- Product: AI validation reports for startup ideas.
- Ask: feedback on whether the report would affect what another indie hacker builds next.

### Priority 5 - r/SaaS

Skip for this launch unless the account has enough posting history.

Use only if the post is about pricing and validation, not "please support my launch."

Title:

`I chose one-time credits instead of SaaS subscriptions for an AI validation tool.`

Angle:

Explain the pricing decision: 3 free reports, then one-time credits. Ask whether this is more trustworthy than forcing a subscription for an occasional validation workflow.

### Priority 6 - r/webdev

Do not post a launch announcement there today.

Use only if there is a permitted Showoff / feedback thread and the post is technical: open-source Next.js app with Supabase, Claude, Dodo Payments, report sharing, and production deployment lessons.

### Priority 7 - Hacker News

Only post if you can use an established account.

Best format:

`Show HN: HypeCheck - AI validation reports for startup ideas`

Keep the body plain and technical. Avoid marketing language.

### Priority 8 - GitHub

After the Product Hunt page is live, add the Product Hunt link to the README and pin / feature the repo where possible.

Use X to drive two actions:

- Product Hunt feedback from indie hackers and builders.
- GitHub stars from developers who want to inspect the open-source stack.
